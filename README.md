# materializamexico.com

Sitio estático del Grupo Materializa. Netlify publica automáticamente cada cambio en `main`.

- `index.html`, `doma.html`, `guizar.html`, `umbau.html`, `kl.html`: páginas principales.
- `blog/`: artículos (un folder por artículo con `index.html`).
- `sitemap.xml`, `robots.txt`: SEO. Actualizar `sitemap.xml` al agregar artículos.
- No publicar ofertas de inversión, rendimientos ni datos personales.
